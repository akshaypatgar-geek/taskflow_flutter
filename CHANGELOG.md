# Changelog

## [1.0.0] - 2026-03-24

### Added
- Task CRUD with real-time WebSocket updates
- Offline-first architecture with Hive CE caching
- Cursor-based pagination for task lists
- Category management (list, create)
- User profile with editable display name
- Adaptive layout with NavigationRail for wide viewports
- Dark mode support with Material 3 theming

### Architecture
- Clean architecture: domain use cases, repository interfaces, BLoC state management
- Dependency injection via GetIt
- Typed routing with GoRouter + sealed extras
- Design token system (AppTokens, AppDecorations)
